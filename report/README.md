# BTP-I report

`BTP_Report.pdf` is the 34-page LaTeX review draft for Ayush Goel, 23CH10092, supervised by Prof. Nikita Saxena, Department of Chemical Engineering, IIT Kharagpur.

The editable project is in `latex/`. Open `main.tex` with all supporting files and compile with XeLaTeX. The bibliography is embedded, so no separate BibTeX or Biber step is needed. Tectonic also compiles the source.

The document reports the existing GPU experiments. It does not include newly retrained or corrected-loss results. Its declaration and certificate remain unsigned. Student review and supervisor approval are still required before treating the draft as a final submission.
